# 方块小天地 · block-world-game

一个适合小学生编程启蒙的网页版 2D 方块世界。只有 HTML、CSS 和 JavaScript，不使用框架，不需要安装依赖，也不会加载网络图片。

## 怎么开始

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**。
2. 解压下载的文件，双击 `index.html`，用电脑上的 Chrome、Edge 或 Firefox 打开。
3. 点击一下游戏画面，然后开始探索！三个网页文件要放在同一个文件夹里。

GitHub 的文件页面显示的是代码；要玩游戏，请下载后打开 `index.html`。

## 怎么玩

| 操作 | 方法 |
| --- | --- |
| 左右移动 | 方向键 ← / →，也可以用 A / D |
| 跳跃 | 空格、↑ 或 W；站稳后才能再次跳跃 |
| 放置方块 | 选择“放置方块”，鼠标左键点击空格子 |
| 删除方块 | 选择“删除方块”后左键点击，或直接右键点击方块 |
| 重新开始 | 点击“重新开始”，恢复初始世界和角色位置 |

方块会挡住角色，角色可以站在方块上，也可以搭楼梯往高处跳。角色所在的位置不能放方块。最底下一层是不能删除的地基，防止角色掉出世界。点击其他地方或切换窗口时，角色会停止移动。

第一版面向电脑键盘和鼠标；暂不支持触屏操作。世界只保存在当前页面，刷新、关闭页面或重新开始都会清除建造内容。

## 每个文件做什么

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页的结构：标题、工具按钮、游戏画布和玩法提示 |
| `style.css` | 网页的外观：颜色、大小、间距和窄屏排版 |
| `game.js` | 游戏规则：地图、键盘移动、重力跳跃、碰撞、鼠标建造和绘画 |
| `README.md` | 你正在读的说明书 |

## 一起学编程

`game.js` 用中文注释分成了六个部分，可以一段一段读。

- **变量**：`SPEED` 是走路速度，`JUMP` 是跳跃力度。先试着只改一个数字，再刷新观察变化。
- **数组**：`world` 是格子地图，`0` 表示空气，`1` 表示草方块，`2` 表示泥土。
- **条件**：`if` 帮我们判断“有没有碰到方块”“是不是站在地面上”。
- **函数**：`update` 更新角色的位置，`draw` 把世界画出来。
- **循环**：`requestAnimationFrame` 让浏览器一帧一帧更新画面。

小挑战：把天空改成傍晚的颜色；让角色穿上你喜欢的衣服；搭一座能跳到顶部的小楼梯。每次只改一处，保存后刷新浏览器看看结果。
